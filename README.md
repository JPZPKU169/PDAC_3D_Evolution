# PDAC_3D_Evolution
This repository provides code to reproduce key results described in "Three-dimensional ductal topology resolves lineage architecture and structural organization in pancreatic cancer precursors".

## Dependencies
### Operating system
The analyses were performed on Windows and Linux platforms:  
**Windows**: Windows 11, used for MATLAB-based 3D reconstruction, spatial analyses, and visualization.  
**Linux**: Rocky Linux 8.10, used for whole-genome sequencing data processing and bioinformatics analyses on a high-performance computing (HPC) cluster.
